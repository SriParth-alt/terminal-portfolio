# parth@srivastav:~$

An interactive terminal portfolio. Single HTML file — no framework, no build step, no dependencies.

**Live:** [terminal-portfolio-pi-blue.vercel.app](https://terminal-portfolio-pi-blue.vercel.app)

## What it is

A working shell in the browser. Everything about me lives behind a command:

| command | does |
|---|---|
| `about` / `whoami` | who I am and what I work on |
| `projects` | PyKV, GridMind, Harmony — with benchmarks |
| `skills` | languages, systems, infra, ML stack |
| `certs` | certifications |
| `education` | degree, GPA, coursework |
| `contact` | email, GitHub, LinkedIn |
| `resume` | one-screen summary |
| `ls` / `cat <file>` | browse the filesystem |
| `open github` | jump to a link |
| `theme <name>` | green · amber · ice · matrix |
| `neofetch` | system info, obviously |

Tab autocompletes, `↑`/`↓` walks history, `Ctrl+L` clears. There are easter eggs.

Not a terminal person? Every command has a button under the header.

## Stack

Vanilla HTML/CSS/JS. Canvas matrix rain, CSS scanline + phosphor-flicker overlays,
a small command parser with history and autocomplete. ~34 KB, one file, zero requests
beyond the webfont.

## Run it

```bash
open index.html          # that's it
```

## Deploy

Static — drop it on Vercel, Netlify or GitHub Pages with no build command.
